# Tap the Red Button

Smartphone ke liye banaya gaya reflex game. 6 yellow arcade buttons hain; har baar ek button red hota hai, use jitna jaldi ho sake tap karo.

## Kaise khelein

1. Time limit chuno: **10 sec**, **30 sec** ya **60 sec**.
2. **Start** dabao. 3-2-1 ke baad game shuru hota hai.
3. Jo ball red ho, use tap karo. Tap karte hi red gayab ho jata hai aur 1 second se kam (0.25–0.90 s) mein kisi doosri ball pe red aata hai.
4. Har tap ka reaction time (second mein) board ke niche line se likha jata hai.
5. Time khatam hone par result dikhta hai: kitne second mein kitne ball click kiye, average / fastest / slowest time, galat tap aur speed (ball/sec).

Yellow ball pe tap karna "galat tap" gina jata hai. Har mode ka best score isi browser mein save rehta hai.
